# Instagram 原寸画像オープナー（Chrome 拡張）

Instagram の個別ポストを開いた状態で右クリックすると、そのポストの画像を原寸サイズで別タブに開ける Chrome 拡張です（Manifest V3）。

## 機能

個別ポストのページ（`instagram.com/p/xxxx/`、`/reel/xxxx/`、`/ユーザー名/p/xxxx/` など）で右クリックすると、次のメニューが表示されます。

| メニュー | 動作 |
| --- | --- |
| このポストの画像をすべて原寸で開く | カルーセル（複数枚）投稿の場合も全画像を、元のタブの右隣に順番に開きます |
| 表示中の画像だけを原寸で開く | カルーセルで今表示しているスライドの画像だけを開きます |

- フィードからポストをクリックしてモーダル表示した場合も、URL が `/p/...` になっていれば使えます。
- 動画のスライドはスキップします。

## 仕組み

1. URL のショートコードからメディア ID を算出し、Instagram の内部 API（`/api/v1/media/{id}/info/`）をログイン中のセッションで呼び出して、各画像の候補の中から最大解像度の URL を取得します。
2. API が使えない場合（未ログインなど）は、ページ上の `<img>` の `srcset` から最大サイズの URL を選ぶ方法にフォールバックします（この場合、カルーセルは読み込み済みのスライドのみ）。

※ 「原寸」は Instagram サーバー上に保存されている最大サイズです（Instagram はアップロード時に通常幅 1080px 程度へ縮小しています）。

## Windows の Chrome へのインストール

1. この `instagram-original-image-opener` フォルダを PC の任意の場所に置きます（例: `C:\Users\<ユーザー名>\chrome-extensions\instagram-original-image-opener`）。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、手順 1 のフォルダ（`manifest.json` があるフォルダ）を選択します。
5. Instagram にログインした状態でポストを開き、ページ上で右クリック → メニューから実行します。

Edge など Chromium 系ブラウザでも同じ手順（`edge://extensions`）で使えます。

## 注意

- Instagram の仕様変更により動作しなくなる可能性があります。
- 取得した画像の利用は、著作権および Instagram の利用規約の範囲内で行ってください。
